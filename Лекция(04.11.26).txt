1. Отличие коллайдера от коллизии.
Коллайдер (Collider) — компонент, задающий форму объекта для столкновений. Коллизия (Collision) — само физическое взаимодействие объектов при столкновении.

2. Отличие while от do while.
while — сначала проверяет условие, затем выполняет цикл.
do while — сначала выполняет код, затем проверяет условие. Поэтому выполняется минимум один раз.

3. Методы Web-запросов.
GET — получение данных.
POST — отправка данных.
PUT — полное обновление данных.
PATCH — частичное обновление данных.
DELETE — удаление данных.

4. Когда используется OnCollision и OnTrigger?
OnCollision — когда нужно обработать физическое столкновение объектов.
OnTrigger — когда нужно обнаружить пересечение объектов без физического отталкивания, например вход персонажа в зону.

5. Для чего нужен интерфейс Input?
Input в Unity используется для получения действий пользователя: нажатий клавиш, движения мыши, касаний экрана и нажатий кнопок. Например, для управления персонажем.
